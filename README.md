# Учебный помощник в Telegram

Telegram-бот принимает текстовый учебный вопрос в личном чате и запрашивает объяснение у модели через OpenAI Responses API. Приложение передаёт текст вопроса в OpenAI и отправляет полученный ответ в Telegram.

## Установка

Требуется Python 3.11 или новее. Выполните команды из папки проекта в PowerShell.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Настройка и запуск

Имена параметров перечислены в `.env.example`. Программа читает окружение. Укажите собственные значения в текущем сеансе PowerShell.

```powershell
$env:TELEGRAM_BOT_TOKEN='<ваше значение>'
$env:OPENAI_API_KEY='<ваше значение>'
$env:OPENAI_MODEL='<ваше значение>'
.\.venv\Scripts\python.exe bot.py
```

Укажите идентификатор модели, доступной вашему проекту OpenAI, в `OPENAI_MODEL`. Отправьте `/start`, затем текстовый вопрос. Приложение не ведёт локальные списки пользователей или журналы сообщений. Запросы к OpenAI могут тарифицироваться.

Рабочие ключи, базы и файлы состояния предназначены для локального хранения. Проверяйте подключение в собственном тестовом чате или канале.
